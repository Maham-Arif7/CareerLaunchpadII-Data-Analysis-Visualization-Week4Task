## Overview
This task focused on learning the basics of Python data visualization using libraries like Matplotlib and Seaborn. The goal was to practice creating different types of plots, customizing them, and understanding how to represent data effectively.

## Contents of Work
Environment setup in Jupyter Notebook.

Importing libraries: pandas, numpy, matplotlib, seaborn.

Loading dataset (YouTube channels data).

### Creating basic plots:

Line chart (trend over time).

Bar chart (category comparison).

Pie chart (proportions).

Scatter plot (relationships).

Customizing visuals with labels, titles, colors, and ticks.

## How to Use
Open the notebook and run cells step by step.

Each section produces a graph.

Explain what each visualization shows.
